# 🧹 CleanPro - Professional Cleaning Marketplace

CleanPro is a full-stack mobile marketplace built with React Native, Expo, and Firebase. It allows users to book cleaners, track their location, and make payments via EasyPaisa/JazzCash.

## 🚀 Features
- 📱 **Mobile App:** Book cleaners, track live location, view booking history.
- 💻 **Admin Dashboard:** View bookings, verify payments, track revenue.
- ☁️ **Cloud Database:** Firebase Firestore for real-time updates.
